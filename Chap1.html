Computer System


 1.1 Introduction of Computer

1.1.1 Definition, Characteristics and Applications

Computer: An electronic device that accepts data as input, processes it according to instructions, stores it, and produces useful information as output.

Characteristics

* High speed
* Accuracy
* Large storage capacity
* Automation
* Versatility
* Reliability
* Diligence (does not get tired)

Applications: Education, banking, business, healthcare, communication, entertainment, science, transportation, etc.

1.1.3 Measurement Units

Processing speed:

* Hz = Hertz
* KHz = 1,000 Hz
* MHz = 10⁶ Hz
* GHz = 10⁹ Hz

Storage units:

* 1 bit = 0 or 1
* 8 bits = 1 Byte
* 1 KB = 1024 Bytes
* 1 MB = 1024 KB
* 1 GB = 1024 MB
* 1 TB = 1024 GB
* 1 PB = 1024 TB

---

1.1.4 Types of Computers

* **Supercomputer:** Fastest and most powerful; used for weather forecasting, scientific research, simulations, etc.
* **Mainframe:** Large computer that handles huge amounts of data and many users; used by banks and large organizations.
* **Minicomputer:** Medium-sized computer, more powerful than early microcomputers and designed for multiple users.
* **Microcomputer:** Small computer generally designed for individual users, such as desktops and laptops.

---

1.1.5 Mobile Computing

Mobile computing means using computing devices and networks while moving from one place to another.

Examples: Smartphones, tablets, laptops.

Applications:Mobile banking, online learning, GPS/navigation, video calls, social media, online shopping, etc.

---

1.2 Computer System and I/O Devices

1.2.1 Computer Architecture and Organization

Computer Architecture: The programmer-visible design and functions of a computer system.

Computer Organization: How the physical components of a computer are arranged and work together.

**Simple difference:**
Architecture = **What the computer does**
Organization = **How the computer does it**

---

1.2.2 Components of Computer System

1. Input Unit: Enters data and instructions into the computer.
2. Processing Unit (CPU): Processes data and controls operations.
3. Memory Unit: Temporarily stores data and instructions.
4. Storage Unit: Permanently stores data and programs.
5. Output Unit: Presents processed information to the user.

CPU = ALU + CU + Registers

ALU:  Performs arithmetic and logical operations.
CU: Controls and coordinates computer operations.
Registers:  Very fast temporary storage inside the CPU.

---

 1.2.3 Microprocessor

A microprocessor is a programmable electronic chip that performs the functions of a CPU.

Clock Speed: Number of clock cycles performed per second, measured in Hz, MHz or GHz.

        Word Length: Number of bits a processor can process at one time, e.g., 32-bit or 64-bit.

Main functions:

* Performs calculations
* Processes data
* Controls operations
* Executes instructions

---

1.2.4 Bus System

A bus is a communication pathway used to transfer information between computer components.

Data Bus: Carries data.
>Address Bus: Carries the address/location of data.
Control Bus: Carries control signals and commands.

*Easy memory trick:*
Data = What
Address = Where
Control = How

---

# 1.2.5 Primary Memory

**Primary memory** is memory directly accessible by the CPU.

### RAM

**RAM (Random Access Memory):** Temporary, volatile memory used while programs are running.

Types:

* **SRAM:** Faster, expensive; commonly used for cache.
* **DRAM:** Slower than SRAM, cheaper; commonly used as main memory.

### ROM

**ROM (Read Only Memory):** Non-volatile memory that stores permanent or semi-permanent instructions.

Types:

* PROM
* EPROM
* EEPROM

### Cache Memory

Very fast memory located close to/within the CPU that stores frequently used data and instructions.

### Buffer

A temporary memory area used to hold data while it is being transferred between devices with different speeds.

---

# 1.2.6 Secondary Memory

**Secondary memory** stores data permanently and has larger capacity than primary memory.

### Magnetic Disk

Uses magnetic material to store data.
**Example:** Hard Disk Drive (HDD).

### Flash Memory

Non-volatile electronic memory with no moving parts.
**Examples:** SSD, pen drive, memory card.

### Optical Disk

Stores data using laser technology.
**Examples:** CD, DVD, Blu-ray.

### External Storage Devices

Storage devices connected externally to a computer.
**Examples:** External HDD, external SSD, pen drive.

### Memory Stick

A small portable flash-storage device used to store and transfer data.

---

1.2.7 Input Devices

Input devices are used to enter data and instructions into a computer.

Keyboard: Enters text, numbers and commands.
Mouse: Pointing device used to select and control objects.
Scanner: Converts paper documents/images into digital form.
Light Pen: Pen-shaped pointing device used with compatible displays.
OMR: Reads marked answers on specially designed forms.
OCR: Converts printed/typed text into editable digital text.
BCR: Reads barcodes.
MICR: Reads characters printed with magnetic ink, mainly used in banking.
Touch Screen: Accepts input by touching the screen.
Microphone: Inputs sound/voice.
Digital Camera: Captures images/videos in digital form.

---

# 1.2.8 Output Devices

output devices display or produce processed information.

### Monitor

Displays text, images and videos.

* **LCD:** Liquid Crystal Display.
* **LED:** Light Emitting Diode display; generally thinner and more energy-efficient than older LCD-backlit designs.

### Printers

* **Dot Matrix:** Impact printer that prints using dots; relatively noisy.
* **Inkjet:** Sprays tiny droplets of ink onto paper.
* **Laser:** Uses laser and toner; fast and produces high-quality text.

### Speaker

Produces sound output.

---

# 1.2.9 Hardware Interfaces

**Hardware interface:** A connection/interface that allows computer hardware devices to communicate.

* **Parallel Port:** Transfers multiple bits simultaneously; older printers commonly used it.
* **Serial Port:** Transfers data sequentially, one bit at a time.
* **USB:** Universal Serial Bus; connects devices and transfers data/power.
* **HDMI:** Transfers high-quality digital audio and video.
* **Expansion Slots:** Slots on the motherboard used to install expansion cards such as graphics, sound or network cards.

Web Technology I

            
INTRODUCTION TO WEB DEVELOPMENT

 

Web technology refers to the set of tools, techniques, and skills used
to build and host a website on the internet or on a private intranet.
Web development can range from a simple static page to a complex,
data-driven web application such as an e-commerce site or a social
networking platform.
 
1.1 Types of Web Developers

    
   
  1.   Front-end Developer (Client-side Developer)
       Builds the part of a website that users see and interact with
       directly in the browser. A competent front-end developer is
       usually skilled in HTML, CSS, and JavaScript.
 
    2. 
 
  2. 
     Back-end Developer (Server-side Developer)
       Handles the server-side logic of a website - processing data,
       managing databases, and connecting the server to the front end.
 
    3. 
 
  3. 
     Full-stack Developer
       Works on both the front end and back end, and understands the
       complete development process from start to finish.

2. THE INTERNET
 
The internet is a vast, global network made up of many interconnected
smaller networks. Data travels from computer to computer and network
to network using packet-switching technology and standard
communication protocols.
 
2.1 Common Uses of the Internet
    Research, education, entertainment, job searching, online
    shopping, communication, gathering product feedback, blogging,
    financial transactions, product promotion, reading online
    journals/magazines, and getting real-time updates.
 
2.2 Positive Impacts of the Internet
    - Provides a fast, cheap, and easy medium of communication
    - Enables information sharing and browsing
    - Allows file transfer between users
    - Gives access to a worldwide audience
    - Supports effective, low-cost promotion of products/services
    - Serves as a source of entertainment
    - Improves supply chain management (SCM)
 
2.3 Negative Impacts of the Internet
    - A common channel for spreading malware such as viruses and worms
    - Increases risks of data theft, privacy invasion, and tampering
    - Widens the digital divide between those with and without access
    - Enables misuse of personal data
    - Can affect physical health when overused
    - Can waste time on unproductive activities

3. WEB PAGE, WEBSITE, WEB BROWSER, AND SEARCH ENGINE
 
3.1 Web Page
    A hypertext document available on the World Wide Web; it is the
    basic unit of the web and can contain text, links, images, audio,
    video, and other embedded content. It is typically built using
    HTML and can contain hyperlinks that let a user move to another
    page.
 
3.2 Website
    A collection of related web pages, connected through hyperlinks
    and published together by an organization or individual. A
    website usually has a home page along with several other pages.
 
3.3 Web Browser
    Software used to access and display information on the web. When
    a user requests a page, the browser fetches data from the web
    server and renders the HTML, CSS, and JavaScript content on
    screen. Examples: Google Chrome, Microsoft Edge, Safari, Opera.
 
3.4 Search Engine
    A web-based tool that helps users locate information on the World
    Wide Web based on keywords they type in. It searches through its
    index of web content to return relevant results. Examples:
    Google, Yahoo, Bing.

4. CONTENT MANAGEMENT SYSTEM (CMS)
 
A Content Management System is a tool that allows users to create,
manage, and update website content without needing deep technical or
programming knowledge. Instead of writing all the underlying code
manually, a CMS handles the basic infrastructure so the user can
focus on content and presentation.
 
Popular open-source CMS platforms: WordPress, Joomla, Drupal,
Magento (commonly used for e-commerce).

5. HTML (HYPERTEXT MARKUP LANGUAGE)
 
HTML is the markup language used to create web pages. It consists of
a set of tags that tell a web browser how to display content. HTML is
platform-independent and is not a programming language like C, C++,
Java, or PHP - it only describes structure and layout.
 
HTML was developed by Tim Berners-Lee in 1990 at CERN. It has evolved
through several versions, including HTML 1.0, 2.0, 3.2, 4.01, and the
current HTML5.
 
5.1 Uses of HTML
    - Creating the basic layout/design of a web page
    - Embedding text, images, multimedia, and links
    - Structuring documents with paragraphs, formatting, lists, etc.
    - Embedding scripts such as CSS and JavaScript to control the
      look and behaviour of a page
 
5.2 Advantages of HTML
    - Flexible and user-friendly
    - Easy to maintain
    - Simple to learn and understand
    - Compatible with search engines
    - Efficient and reliable
    - Supports interactive linking between pages
 
5.3 Disadvantages of HTML
    - Difficult to create visually rich pages using HTML alone
    - Hard to build a full website with only HTML
    - Cannot create dynamic web pages by itself
    - It is a markup language, not a programming language
    - No single, universally agreed HTML standard
    - Limited mainly to layout and hyperlink-based navigation

5.5 Headings
    HTML provides six levels of headings, from <h1> (largest/most
    important) to <h6> (smallest), used to structure a document's
    content hierarchy.
 
5.6 The <font> Tag
    A paired tag used to control the size, colour, and typeface of
    text.
        - size: sets font size (values 1-7, with 3 as the default)
        - color: sets font colour, either by name (e.g. red) or by a
          hexadecimal RRGGBB colour code
        - face: sets the font family/typeface
 
5.7 Paragraphs and Line Breaks
    - <p>...</p>: defines a paragraph; browsers add space before and
      after it automatically
    - <br>: inserts a single line break without extra spacing (a
      singular tag)
 
5.8 Comments in HTML
    Written as <!-- comment text -->, comments are ignored by the
    browser and are not displayed on the page; they are used to leave
    notes within the code.
 
5.9 Text Formatting Tags
    Tags such as <b>/<strong> (bold), <i> (italic), <u> (underline),
    <big>/<small> (text size), <sub>/<sup> (subscript/superscript),
    <abbr> (abbreviation), <address>, and <q> (short quotation) are
    used to change how text appears.
 
5.10 Lists
    - Ordered List: <ol>...</ol> with each item in <li>...</li>;
      items are automatically numbered.
    - Unordered List: <ul>...</ul> with items in <li>...</li>; items
      are marked with bullets (disc, circle, or square).
    - Description List: <dl> defines the list, <dt> defines a
      term/name, and <dd> describes that term.
 
5.11 Hyperlinks
    Created with the <a> tag, hyperlinks let users navigate between
    documents or to different parts of the same document.
        Syntax: <a href="URL">link text</a>
    Types of links:
        1. Internal link - links to another location within the same
           page (e.g. a "back to top" link)
        2. Local link - links to another page within the same website
        3. External link - links to a page on a different website
 
5.12 Tables
    A table displays data in rows and columns, built with the
    <table> tag and its sub-elements:
        <tr>  - table row
        <th>  - table heading cell
        <td>  - table data cell
        <caption> - table caption
    Cells can be merged across rows using the rowspan attribute, or
    across columns using the colspan attribute.

6. HTML FORMS
 
A form is a section of a web page containing fields used to collect
information from visitors. Forms are created using the <form> tag,
which wraps around the individual input elements.
 
6.1 Form Attributes
    - method: specifies how form data is sent (GET or POST)
    - action: specifies where the form data is sent when submitted
    - enctype: specifies how the data should be encoded before
      sending
    - name: names the form
    - target: specifies where the response should be displayed
 
6.2 Common Form Controls
    - Text field: <input type="text">
    - Password field: <input type="password">
    - Radio button: <input type="radio"> (choose one from a group)
    - Checkbox: <input type="checkbox"> (choose multiple options)
    - Submit button: <input type="submit">
    - Reset button: <input type="reset">
    - Dropdown list: <select> with <option> tags
    - Multi-line text: <textarea>
    - Other input types: number, email, url, date

7. CSS (CASCADING STYLE SHEETS)
 
CSS is a style-sheet language used to control how an HTML document
looks - its colours, fonts, spacing, and layout - separately from its
content and structure.
 
7.1 Advantages of CSS
    - Separates content from presentation
    - Makes websites easier to maintain
    - Reduces repeated formatting code
    - Improves page loading speed
    - Supports responsive design across devices
    - Keeps styling consistent across many pages
 
7.2 Ways to Add CSS
    1. Inline CSS: written directly inside an HTML tag's style
       attribute
    2. Internal/Embedded CSS: written inside a <style> block in the
       document's <head>
    3. External CSS: written in a separate .css file and linked using
       <link rel="stylesheet" href="style.css">
 
7.3 CSS Syntax
        selector {
            property: value;
        }
 
7.4 Common CSS Properties
    - Text: color, font-family, font-size, text-align,
      text-decoration
    - Background: background-color, background-image
    - Box model: width, height, margin, padding, border
    - Positioning: position, top, left, display, float

8. JAVASCRIPT
 
JavaScript is a high-level, interpreted scripting language used to
add interactivity and dynamic behaviour to web pages. It runs mainly
on the client side, inside the user's browser.
 
8.1 Features of JavaScript
    - Executes on the client side (in the browser)
    - Can dynamically change HTML content
    - Handles user events (clicks, key presses, etc.)
    - Used for form validation before submission
    - Can display popup dialogue boxes (alert, confirm, prompt)
 
8.2 Ways to Add JavaScript
    1. Inline, within a <script> block
    2. Internally, placed inside the <head> or <body>
    3. Externally, by linking a separate .js file with
       <script src="script.js"></script>

9. WEB SERVERS AND HOSTING
 
9.1 Web Server
    Software that stores web page files and delivers them to client
    browsers upon request. Examples: Apache, Microsoft IIS, Nginx.
 
9.2 Domain Name
    A human-readable address used to identify a website on the
    internet, e.g. example.com, instead of using its numeric IP
    address.
 
9.3 Web Hosting
    A service that allows individuals or organizations to publish and
    store their website's files on a server so it can be accessed via
    the internet. Common types include Shared Hosting, VPS (Virtual
    Private Server) Hosting, Dedicated Hosting, and Cloud Hosting.

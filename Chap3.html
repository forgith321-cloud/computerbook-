3. Computer Software and Operating System (12 Hours)


3.1 Concept of Software

3.1.1 Definition of Software


Software is a set of instructions, programs, or data that tells a computer how to perform specific tasks. Unlike hardware, which is the physical part of a computer, software is intangible - it cannot be touched but can be stored, executed, and modified. Software acts as the bridge between the user and the computer hardware, enabling the hardware to perform useful work.

3.1.2 Categories of Software: System, Utility, Application, Web Based, Mobile Apps

- System Software: Software that manages and controls computer hardware so that application software can run. It works closely with the computer at a fundamental level. Examples include operating systems (Windows, Linux) and device drivers.
- Utility Software: Software designed to help analyze, configure, optimize, or maintain a computer. It performs a single task or a small range of tasks. Examples include antivirus programs, disk cleanup tools, and file compression tools.
- Application Software: Software designed to help users perform specific tasks such as word processing, spreadsheet calculations, or image editing. Examples include Microsoft Word, Excel, and Photoshop.
- Web Based Software: Software that runs inside a web browser rather than being installed directly on a computer. It is accessed over the internet and often stores data on remote servers. Examples include Google Docs and Gmail.
- Mobile Apps: Software applications specifically designed to run on mobile devices such as smartphones and tablets. Examples include WhatsApp, Instagram, and mobile banking apps.


3.2 Concept of Operating System

3.2.1 Introduction to Operating System

An Operating System (OS) is system software that acts as an intermediary between the computer user and computer hardware. It manages hardware resources, provides a platform for running application software, and offers a user interface for interaction. Common examples include Windows, macOS, Linux, and Android.

3.2.2 Role of Operating System

The operating system plays several key roles:
- Acts as a resource manager, allocating hardware resources such as CPU, memory, and storage to different programs.
- Provides a user interface (graphical or command-line) so users can interact with the computer.
- Acts as an intermediary between application software and hardware, allowing programs to run without needing to manage hardware directly.
- Ensures security and controlled access to system resources.


3.2.3 Functions of an Operating System

- Process Management: Creating, scheduling, and terminating processes, and managing CPU time among them.
- Memory Management: Allocating and deallocating memory space to programs as needed.
- File Management: Organizing, storing, retrieving, and naming files and directories.
- Device Management: Controlling and coordinating the use of hardware devices through device drivers.
- Security and Access Control: Protecting data and resources from unauthorized access.
- User Interface: Providing a way for users to interact with the system, either through a command line or graphical interface.


3.2.4 Operating System Terminology: Multiprogramming, Multitasking, Multiprocessing and Distributed

- Multiprogramming: The ability of an operating system to keep multiple programs in memory at the same time, so that when one program is waiting (e.g., for input/output), the CPU can switch to executing another, improving CPU utilization.
- Multitasking: The ability to execute multiple tasks or processes seemingly at the same time by rapidly switching between them, giving the user the impression that they are running simultaneously.
- Multiprocessing: The use of two or more CPUs (processors) within a single computer system, allowing multiple processes to be executed truly in parallel.
- Distributed Operating System: An operating system that manages a group of independent computers connected over a network, making them appear to users as a single coherent system, sharing resources and processing power.

3.3 Windows Operating System

3.3.1 Introduction to GUI Based Operating System and Its Features

A GUI (Graphical User Interface) based operating system allows users to interact with the computer through visual elements such as windows, icons, menus, and pointers, rather than typing text commands. Windows OS is a widely used GUI-based operating system. Its features include a desktop environment, drag-and-drop functionality, multitasking through windows, taskbar and start menu, and support for a wide range of hardware and software.

3.3.2 Working in Desktop Application and Window Environment

The desktop is the main screen area displayed after logging into Windows, containing icons, shortcuts, and a taskbar. A "window" refers to a rectangular area on the screen used to display a running application. Users can open, resize, minimize, maximize, close, and switch between multiple windows, allowing several applications to be used at once.

3.3.3 Manage Files and Folders with File Explorer

File Explorer is the file management application in Windows used to browse, organize, and manage files and folders. It allows users to create, rename, copy, move, delete, and search for files and folders, as well as view files in different formats (list, details, icons) and navigate through the drive and folder hierarchy.

3.3.4 Customize the Start Screen and Desktop

Windows allows users to personalize their computing environment, including changing the desktop background/wallpaper, adjusting screen resolution and themes, pinning or unpinning apps to the Start menu or taskbar, rearranging tiles on the Start screen, and adjusting icon sizes and arrangement.

3.3.5 Installing and Removing Devices

Windows provides tools (such as Device Manager and Settings) to install new hardware devices (like printers, scanners, or USB drives) by installing the appropriate drivers, and to safely remove or uninstall devices that are no longer needed, ensuring proper disconnection without data loss or system errors.

3.3.6 Manage Passwords and Privacy Levels

Windows includes features to manage user account passwords, set up PINs or biometric login, and configure privacy settings that control what data apps can access (such as location, camera, microphone, and contacts), helping protect user data and maintain system security.

3.3.7 Use of Control Panel, System Tools and Accessories

- Control Panel: A centralized location for changing system settings, such as adding/removing programs, managing user accounts, adjusting display and sound settings, and configuring network options.
- System Tools: Built-in utilities such as Disk Cleanup, Disk Defragmenter, System Restore, and Task Scheduler used for maintaining and optimizing system performance.
- Accessories: Small built-in applications such as Notepad, Paint, Calculator, and Snipping Tool that come bundled with Windows for basic tasks.

3.4 Open Sources and Mobile Operating System

3.4.1 Concept of Open Source Operating System

An open source operating system is one whose source code is made publicly available, allowing anyone to view, modify, and distribute it. This encourages collaborative development, transparency, and customization, and is typically distributed free of cost, unlike proprietary operating systems such as Windows.

3.4.2 Introduction to Linux and UNIX

- UNIX: One of the earliest multi-user, multitasking operating systems, developed in the 1970s. It is known for its stability, security, and is widely used in servers and workstations. UNIX is generally proprietary and developed by different vendors.
- Linux: An open-source operating system kernel inspired by UNIX, created by Linus Torvalds in 1991. Linux is free, highly customizable, and forms the basis for many operating system distributions used in servers, desktops, and embedded systems.

3.4.3 Linux Distributions

A Linux distribution (or "distro") is a complete operating system built around the Linux kernel, bundled with additional software, utilities, and a package management system. Popular Linux distributions include Ubuntu, Fedora, Debian, Linux Mint, and CentOS, each tailored for different types of users and use cases.

3.4.4 Concept of Mobile Operating System

A mobile operating system is software specifically designed to run on mobile devices such as smartphones and tablets. It manages hardware resources like the touchscreen, camera, and cellular connectivity, and provides a platform for running mobile applications, typically optimized for smaller screens, touch input, and battery efficiency.

3.4.5 Types of Mobile Operating System

- Android: An open-source mobile operating system developed by Google, based on the Linux kernel, widely used across many device manufacturers.
- iOS: A proprietary mobile operating system developed by Apple, used exclusively on Apple devices such as the iPhone and iPad.
- Other mobile operating systems (historically) include Windows Phone, BlackBerry OS, and Symbian, though these have significantly declined in usage or been discontinued.

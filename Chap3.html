            # 3. Computer Software and Operating System — Short Notes

## 3.1 Concept of Software

### 3.1.1 Definition of Software

**Software** is a collection of programs and instructions that tells a computer **what to do**.

**Example:** Windows, MS Word, Chrome, Calculator.

---

### 3.1.2 Categories of Software

1. **System Software:** Controls and manages computer hardware.
   *Example:* Windows, Linux.

2. **Utility Software:** Performs maintenance and protection tasks.
   *Example:* Antivirus, disk cleanup.

3. **Application Software:** Helps users perform specific tasks.
   *Example:* MS Word, Excel, Photoshop.

4. **Web-Based Software:** Applications that run through a web browser/internet.
   *Example:* Gmail, Google Docs.

5. **Mobile Apps:** Software designed for smartphones and tablets.
   *Example:* WhatsApp, Google Maps.

---

# 3.2 Concept of Operating System

### 3.2.1 Introduction to Operating System

An **Operating System (OS)** is system software that acts as an **interface between the user and computer hardware**.

**Examples:** Windows, Linux, macOS, Android, iOS.

---

### 3.2.2 Role of Operating System

The OS:

* Manages hardware and software.
* Provides an interface for users.
* Manages files and folders.
* Controls running programs.
* Manages memory and devices.
* Provides security.

---

### 3.2.3 Functions of an Operating System

* **Process Management:** Manages running programs.
* **Memory Management:** Allocates and manages memory.
* **File Management:** Creates, deletes and organizes files.
* **Device Management:** Controls input/output devices.
* **Security Management:** Protects data and user accounts.
* **User Interface:** Provides GUI or command-line interface.
* **Resource Management:** Manages CPU, memory, storage and other resources.

---

### 3.2.4 Operating System Terminology

**Multiprogramming:** Several programs are kept in memory so the CPU can work on another when one is waiting.

**Multitasking:** Running multiple tasks/programs apparently at the same time.

**Multiprocessing:** Using two or more processors/CPU cores to perform tasks.

**Distributed Operating System:** Manages multiple networked computers and makes them work together as a system.

### Easy Difference

* **Multiprogramming → Multiple programs**
* **Multitasking → Multiple tasks**
* **Multiprocessing → Multiple processors**
* **Distributed → Multiple computers**

---

# 3.3 Windows Operating System

### 3.3.1 GUI-Based Operating System

**GUI (Graphical User Interface)** allows users to interact with a computer using graphical elements such as **windows, icons, menus and pointers**.

**Features:**

* Icons
* Windows
* Menus
* Mouse/pointer
* Taskbar
* Start menu
* Easy user interaction

---

### 3.3.2 Desktop and Window Environment

**Desktop:** Main screen displayed after Windows starts.

Common elements:

* **Icons:** Represent programs/files.
* **Taskbar:** Shows running applications and system information.
* **Start Menu:** Provides access to applications and settings.
* **Window:** Area in which an application or file is displayed.

---

### 3.3.3 File Explorer

**File Explorer** is a Windows tool used to manage files and folders.

Common operations:

* Create
* Open
* Copy
* Move
* Rename
* Delete
* Search files/folders

---

### 3.3.4 Customize Start Screen and Desktop

Users can customize:

* Desktop background/wallpaper
* Themes
* Icons
* Taskbar
* Start menu
* Screen settings

---

### 3.3.5 Installing and Removing Devices

Windows can automatically detect many devices using **device drivers**.

**Installing:** Connect the device → Windows detects it → driver is installed/configured.

**Removing:** Disconnect or uninstall the device/driver safely.

---

### 3.3.6 Passwords and Privacy

Windows provides security features such as:

* User passwords/PINs
* User accounts
* Screen lock
* Privacy settings
* Permission controls
* Windows Security

---

### 3.3.7 Control Panel, System Tools and Accessories

**Control Panel:** Used to configure system settings.

**System tools:** Help maintain and manage the computer.
Examples: Disk Cleanup, Task Manager, Device Manager.

**Accessories:** Basic programs included with Windows.
Examples: Notepad, Paint, Calculator.

---

# 3.4 Open Source and Mobile Operating Systems

### 3.4.1 Open Source Operating System

An **open-source OS** has source code that is available for users/developers to inspect, modify and redistribute according to its license.

**Example:** Linux.

---

### 3.4.2 Linux and UNIX

**Linux:** An open-source, Unix-like operating system widely used in servers, computers and embedded systems.

**UNIX:** A multiuser, multitasking operating system family originally developed at Bell Labs.

**Difference:** Linux is generally open-source, while traditional UNIX systems have historically been proprietary or commercially licensed.

---

### 3.4.3 Linux Distributions

A **Linux distribution (distro)** is a complete operating system based on the Linux kernel along with software and tools.

Examples:

* Ubuntu
* Debian
* Fedora
* Linux Mint
* Arch Linux

---

### 3.4.4 Mobile Operating System

A **mobile operating system** is an OS designed mainly for mobile devices such as smartphones and tablets.

It manages:

* Apps
* Touchscreen
* Memory
* Battery
* Camera
* Network
* Security

---

### 3.4.5 Types of Mobile Operating Systems

* **Android**
* **iOS**
* HarmonyOS
* KaiOS

---

# 4. Application Package — Short Notes

## 4.1 Introduction to Office Package

An **office package** is a collection of software used for common office and educational tasks.

### Word Processor

Used to create, edit, format and print documents.

**Example:** Microsoft Word.

### Presentation Tool

Used to create and display presentations using slides.

**Example:** Microsoft PowerPoint.

### Spreadsheet Package

Used to organize, calculate and analyze data in rows and columns.

**Example:** Microsoft Excel.

### Database Management System (DBMS)

Software used to **create, store, organize, retrieve and manage data** in databases.

**Example:** Microsoft Access.

---

# 4.2 Domain-Specific Tools
